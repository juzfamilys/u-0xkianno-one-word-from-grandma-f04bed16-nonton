A make.fun bounty entry for **One Word From Grandma**: the single word my Indonesian grandma would text about AI.

> **"Waduh"**

"Waduh" is the classic Indonesian grandma reaction to anything new and alarming — one word, warm, a little baffled, unmistakably grandma. It is exactly what she would send when her grandchild shows her an AI.

## Run it

```sh
python3 main.py
```

This writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python standard library, no dependencies.
